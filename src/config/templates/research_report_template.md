<!--
【模板是什么】
调研报告是调研 Agent 在完成调研任务后输出的结构化结果文档，
记录了调研目标、关键发现、方案对比和建议方案。

【模板的作用】
1. 结果结构化 — 按统一格式组织调研结果
2. 过程可追溯 — 记录调研方法和参考来源
3. 方案可对比 — 提供多维度方案对比

【如何使用本模板】
1. 调研 Agent 通过 static_vars 加载本模板内容
2. 按模板章节顺序填写调研结果
3. [必填] 章节必须填写，[可选] 章节根据调研需要填写

【适用场景】
- 技术调研，重点在方案对比和选型建议
- 资源调研，重点在现有资源清单和复用建议

【与其他模板的关系】
- 上游：基于 solution_template.md 创建
- 下游：产出物可被 execution_plan_template.md 使用
-->
