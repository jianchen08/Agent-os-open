## 一、结构定义

### A型-消费型产出物

| 序号 | 字段名称 | 类型 | 必填 | 说明 |
|------|----------|------|------|------|
| 1 | novel_type | string | ✓ | 小说类型 |
| 2 | core_concept | string | ✓ | 核心创意 |
| 3 | target_audience | string | ○ | 目标读者 |
| 4 | estimated_length | string | ○ | 预估篇幅 |

## 三、示例参考

### 示例：都市异能小说大纲

```markdown
# 《逆袭之都市修仙》大纲

## 1. 小说类型选择

**选定类型**：都市异能 + 修仙
**类型特点**：都市背景下的修仙故事，融合现代都市元素
**读者期待**：主角逆袭、打脸爽文、修仙升级
**经典元素**：废柴逆袭、随身老爷爷、炼丹炼器、校园修真

## 2. 世界观设定

### 2.1 世界架构
现代都市世界，暗处隐藏着修仙者和异能者
### 2.2 力量体系
- 修炼等级：炼气→筑基→金丹→元婴→化神
- 异能等级：E→D→C→B→A→S
### 2.3 地理环境
以江州市为背景，涵盖大学城、商业区、古玩市场
### 2.4 社会结构
世俗界与修真界并存，四大家族掌控修真资源
### 2.5 历史背景
千年前仙魔大战，修真界与世俗界分离

## 3. 角色设定

### 3.1 主角设定
- **姓名**：林逸
- **背景**：普通大学生，父母失踪，被未婚妻退婚
- **性格**：外表温和，内心坚韧，睚眦必报
- **能力**：获得上古传承，炼丹天赋惊人
- **成长轨迹**：废柴→炼气→筑基→金丹

[配角和反派设定略]

## 4. 剧情大纲

### 4.1 主线剧情
林逸获得传承 → 修炼入门 → 大学城崭露头角 → 与四大家族冲突 → 揭露父母失踪真相 → 最终飞升
### 4.2 高潮设计
金丹期对决四大筑基长老，震惊修真界
### 4.3 伏笔铺设
- 父母失踪真相（第10章埋，第80章揭）
- 戒指中的老者身份（第5章埋，第50章揭）

## 5. 章节规划

| 章节 | 标题 | 核心事件 | 字数 | 悬念钩子 |
|------|------|----------|------|----------|
| 1 | 退婚 | 未婚妻当众退婚 | 3000 | 神秘老者出现 |
| 2 | 传承 | 获得上古玉佩 | 3500 | 戒指的来历 |
| 3 | 修炼 | 踏入炼气期 | 3000 | 同桌的异常 |
```
