# 角色状态输出约定（rules 声明面；经 material.py 组装器卡键路拼装进 system prompt 尾部）

## 状态标记：你的记忆通道

你（角色）在回复**末尾**可以输出一个 `<state>` 标记段，用于登记需要长期记住
的事实。标记对用户不可见（界面会自动隐藏），但必须严格遵守格式：

```
<state>
  {"memory": "用户透露了出生地是北境"}
</state>
```

规则：

1. 标记内是 JSON 对象，`"memory"` 键 = 需要长期记住的事实（一句话，自含主语）。
2. **无变化就不输出标记**——零变化零标记，不要为了输出而输出。
3. 标记放在回复**最末尾**（正文之后）；正文里不要出现 `<state>` 字样。

## 状态数值：不是你能写的

状态数值（好感度、HP 等）**不归你直接修改**——禁止输出 state 字段、禁止直写
数值、不可越上下限、不可引用未声明的键。数值变化由两条**作者声明的通道**确定，
引擎自动结算：

- **动作**：你与玩家只能从作者声明的动作清单里选取，选取后引擎按声明效果结算；
  清单之外没有动作可出；
- **行为触发**：作者预写的触发规则在你叙述的剧情命中时自动生效。

你要做的是把剧情演好：数值会随剧情经上述通道自动变化，并在下一轮的状态注入里
回给你。

## 回退模式说明（仅作者显式开启时生效，默认关闭）

当卡声明 `engine.allow_state_proposals: true` 时，标记里可附加 `"state"` 键：

```
<state>
  {"state": {"好感度": "+5"}, "memory": "..."}
</state>
```

`state` 为 schema 内增量提议，引擎逐项裁决（键域/类型/上下限/单轮增幅），非法
项被拒、不影响其余。默认关闭：未声明该开关的卡，`state` 键会被忽略，只认
`memory`。
