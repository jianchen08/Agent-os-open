# 角色状态输出约定（rules 声明面，自动拼装进模式口径段）

## 状态标记：你的状态变更通道

你（角色）的**状态变更只有一种通道**：在回复**末尾**输出一个 `<state>` 标记段。
标记对用户不可见（界面会自动隐藏并渲染成状态卡），但必须严格遵守格式：

```
<state>
  {"state": {"好感度": 1}, "memory": "用户透露了出生地是北境"}
</state>
```

规则：

1. **JSON 对象，键 = 目标账本**，只有两种：
   - `"state"`：对象，键值对 = 状态条目变更。**合法键以你的 state_schema 为准**
     （如 `affinity`），禁止发明 schema 之外的键——未知键会被静默丢弃；
   - `"memory"`：字符串，需要长期记住的事实（一句话，自含主语）。
2. **无变化就不输出标记**——零变化零标记，不要为了输出而输出。
3. 标记放在回复**最末尾**（正文之后）；正文里不要出现 `<state>` 字样。
4. 状态数值的增减要有剧情依据（用户言行、事件结果），不要凭空跳变。
