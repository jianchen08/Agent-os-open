# 系统资源配置清单

> **双维度分类体系**
>
> - **级别维度**：系统级（常用/内置）vs 用户级（自定义）
> - **功能维度**：执行/分析/评估/搜索等

## 1. 系统级工具

### 1.1 任务管理
- **名称**: `task_manage`
- **功能**: 创建、查询、更新任务状态
- **分类**: task（任务）
- **级别**: system
- **权限**: 不需要审批
- **危险操作**: 无

### 1.2 记忆检索
- **名称**: `memory_retrieve`
- **功能**: 搜索和检索相关记忆
- **分类**: memory（记忆）
- **级别**: system
- **权限**: 不需要审批
- **危险操作**: 无

### 1.3 评估
- **名称**: `evaluate`
- **功能**: 评估任务完成度和质量
- **分类**: evaluation（评估）
- **级别**: system
- **权限**: 不需要审批
- **危险操作**: 无

### 1.4 资源搜索
- **名称**: `resource_search`
- **功能**: 搜索 Agent、工具、工作流
- **分类**: search（搜索）
- **级别**: system
- **权限**: 不需要审批
- **危险操作**: 无

## 2. 用户级工具

### 2.1 文件操作
- **名称**: `file_operate`
- **功能**: 读取、写入、搜索文件
- **分类**: file（文件）
- **级别**: user
- **权限**: 部分需要审批
- **危险操作**:
  - 写入系统目录 (`/etc/`, `/sys/`, `C:\Windows\`)
  - 删除操作

### 2.2 代码搜索
- **名称**: `search_code`
- **功能**: 在代码库中搜索代码
- **分类**: search（搜索）
- **级别**: user
- **权限**: 不需要审批
- **危险操作**: 无

### 2.3 Web 获取
- **名称**: `web_fetch`
- **功能**: 获取网页内容
- **分类**: web（网络）
- **级别**: user
- **权限**: 不需要审批
- **危险操作**: 无

### 2.4 Web 搜索
- **名称**: `web_search`
- **功能**: 搜索引擎查询
- **分类**: search（搜索）
- **级别**: user
- **权限**: 不需要审批
- **危险操作**: 无

### 2.5 Bash 执行（危险）
- **名称**: `bash_execute`
- **功能**: 执行 Shell 命令
- **分类**: system（系统）
- **级别**: user
- **权限**: **需要审批**
- **危险操作**:
  - `rm -rf`（危险删除）
  - `format`（格式化磁盘）
  - `del /q`（批量删除）
  - `shutdown`（关机）
  - `reboot`（重启）
  - `mkfs`（创建文件系统）
  - `dd if=`（磁盘写入）
  - `curl`（外部网络请求）
  - `wget`（外部网络请求）

## 3. 系统级 Agent

### 3.1 主控智能体
- **名称**: `MainAgent`
- **类型**: main（主 Agent）
- **分类**: system（系统）
- **级别**: system
- **能力**:
  - 任务理解与分解
  - 资源调度
  - 搜索（Agent/工具/工作流）
  - 执行监督
  - 结果整合
- **可用工具**:
  - task_manage
  - memory_retrieve
  - resource_search ⭐
  - evaluate
  - file_operate
  - search_code
  - web_fetch
  - web_search

## 4. 系统级工作流

### 4.1 任务执行工作流
- **ID**: `task_execution`
- **名称**: 任务执行工作流
- **分类**: execution（执行）
- **级别**: system
- **节点**:
  1. 输入节点
  2. 任务分析（Agent）
  3. 资源搜索（Tool）
  4. 任务分解（Agent）
  5. 执行子任务（Parallel）
  6. 结果评估（Tool）
  7. 输出节点
- **使用工具**: resource_search, evaluate
- **使用 Agent**: main_agent

### 4.2 评估工作流
- **ID**: `evaluation`
- **名称**: 评估工作流
- **分类**: evaluation（评估）
- **级别**: system
- **节点**:
  1. 输入节点
  2. 定义评估标准（Agent）
  3. 完整性检查（Tool）
  4. 正确性检查（Tool）
  5. 质量检查（Tool）
  6. 效率检查（Tool）
  7. 汇总评估（Agent）
  8. 生成报告（Tool）
  9. 输出节点
- **使用工具**: evaluate, file_operate
- **使用 Agent**: main_agent

## 5. 权限策略

### 5.1 系统管理员
- **审批权限**: 可以
- **自动批准**: 所有工具 (`*`)

### 5.2 开发者
- **审批权限**: 不可以
- **自动批准**: 除 bash_execute 外的所有工具
- **需要审批**: bash_execute

### 5.3 只读用户
- **审批权限**: 不可以
- **自动批准**:
  - task_manage（仅查询）
  - memory_retrieve
  - evaluate
  - search_code
  - web_fetch
  - web_search
- **需要审批**:
  - file_operate（写入需要审批）
  - bash_execute

## 6. 使用建议

### 6.1 主 Agent 使用场景
- 复杂任务协调
- 多 Agent 协作
- 资源搜索和选择
- 任务质量把控

### 6.2 工作流使用场景
- **任务执行工作流**: 所有标准任务执行
- **评估工作流**: 每次任务完成后评估质量

### 6.3 权限管理建议
- 开发环境：开发者权限
- 生产环境：系统管理员权限
- 演示环境：只读用户权限

## 7. 扩展指南

### 7.1 添加新的系统级工具
1. 实现工具类
2. 设置 `level=ToolLevel.SYSTEM`
3. 添加到 `config/builtin_tools_config.yaml`
4. 更新本清单

### 7.2 添加新的系统级工作流
1. 创建工作流配置文件
2. 设置 `level=WorkflowLevel.SYSTEM`
3. 确保使用系统级工具和 Agent
4. 更新本清单

### 7.3 升级用户级工具为系统级
- 如果某个工具被频繁使用（几乎每次任务都用）
- 修改其 `level` 为 `system`
- 更新相关文档
