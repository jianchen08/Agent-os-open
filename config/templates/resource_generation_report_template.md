# 资源生成报告模板
#
# 【是什么】Agent 完成资源创建任务后提交的结构化结果文档，记录生成目标、资源清单、验证结果和评估结论。
# 【作用】结果可追溯、质量可验证、资源可索引、问题可定位。
# 【适用场景】新建 Agent 配置、工具脚本、工作流配置等"从无到有"创建资源的任务完成后。

# 资源生成报告

---

## 基本信息 [必填]

> 本次生成任务的元数据，所有字段必填，用于追溯任务来源和执行者。

- **任务ID**: {task_id}
- **生成类型**: {agent / tool / workflow / script / config / document}
- **创建时间**: {YYYY-MM-DD HH:mm:ss}
- **执行Agent**: {agent_name}

---

## 生成概述 [必填]

> 本次生成的目标和范围说明。需包含：生成目标（要创建什么）、生成范围（包含/不包含哪些资源）、核心设计决策（为什么这样生成）。

{modification_overview}

| 序号 | 资源名称 | 资源类型 | 资源路径 | 状态 |
|------|----------|----------|----------|------|
| 1 | {name} | {agent/tool/workflow/script/config/document} | {path} | {成功/失败/部分成功} |

## 资源详情 [必填]

> 每个生成资源的详细说明，每个资源一个子章节。

### 资源 N: {resource_name}

- **类型**: {agent / tool / workflow / script / config / document}
- **用途**: {该资源的核心功能和职责}
- **配置路径**: {配置文件完整路径，无则填"无"}
- **代码路径**: {源代码文件完整路径，纯配置则填"无"}
- **关键配置说明**: {对关键配置项的解释，如工具选择、约束设定等}

| 验证项 | 验证方法 | 结果 | 说明 |

- **结论**: {整体评价和后续建议}
