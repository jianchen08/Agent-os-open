# 执行计划模板

<!--
============================================================
【模板是什么】
执行计划是方案确认后的"任务排期表"，将方案中的任务分解为有序的
任务链，明确每个任务的执行者、依赖关系、验收标准和预估时间。

【模板的作用】
1. 任务可视化 — 清晰展示所有任务及其依赖关系
2. 执行有序化 — 按依赖关系排列执行顺序，支持并行任务
3. 资源可分配 — 明确每个任务需要的 Agent、工具和模板
4. 风险可管理 — 提前识别执行风险并制定应对策略
5. 进度可追踪 — 通过里程碑监控整体进度

【如何使用本模板】
1. 基于已确认的方案文档创建执行计划
2. 将方案中的任务分解为可执行的任务链
3. 按依赖关系排列执行顺序，标注可并行的任务
4. 为每个任务分配 Agent 和验收标准
5. 方案来源字段填写对应的方案文档路径

【适用场景】
- 方案确认后，需要制定具体的执行计划
- 复杂任务需要拆解为多个子任务按序执行
- 多 Agent 协作场景，需要协调任务分配

【与其他模板的关系】
- 上游：基于 solution_template.md（方案文档）创建
- 下游：任务执行结果可用于 ac_refinement_template.md（验收标准细化）
============================================================
-->
