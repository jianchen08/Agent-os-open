# 方案细化报告模板

<!--
【模板是什么】
方案细化报告将已确认方案中的粗粒度描述转化为可执行的具体任务、明确的验收标准和详细的实现细节。

【模板的作用】
1. 方案可执行 — 将抽象方案转化为具体可执行的任务
2. 细节可评审 — 细化内容有据可查，支持评审和确认
3. 任务可分配 — 细化后的任务有明确的执行者和验收标准
4. 风险可控制 — 识别细化过程中发现的新风险

【与其他模板的关系】
- 上游：基于 solution_template.md（方案文档）创建
- 下游：细化后的任务用于 execution_plan_template.md（执行计划）
-->
