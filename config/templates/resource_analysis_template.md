# 资源分析报告模板

<!--
【模板是什么】
资源分析报告是 Agent 在修改资源之前，对目标资源进行调研分析后输出的评估文档，
记录了资源的现状、依赖关系、修改影响、风险评估以及修改建议。

【模板的作用】
1. 现状理解 — 全面评估目标资源的当前状态和不足
2. 依赖梳理 — 明确资源与其他模块的依赖关系，避免遗漏影响
3. 风险预判 — 提前识别修改可能带来的风险，制定缓解措施
4. 方案指导 — 为修改任务提供具体的修改建议和优先级

【与其他报告的关系】
| 阶段 | 使用模板 | 说明 |
|------|----------|------|
| 修改前调研 | resource_analysis_template（本模板） | 分析现状、评估影响 |
| 修改后报告 | resource_modification_report_template | 记录修改内容和验证结果 |
-->
