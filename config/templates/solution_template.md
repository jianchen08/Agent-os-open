# 方案文档模板

<!--
============================================================
【模板是什么】
方案文档是任务执行前的"施工蓝图"，定义了要做什么（需求）、
为什么要做（调研）、怎么做（实施方案）、做到什么程度算完成（验收标准）。

【模板的作用】
1. 统一结构 — 所有方案文档遵循相同结构，降低阅读和评审成本
2. 需求可追溯 — 每个验收项关联到具体需求，确保不遗漏
3. 方案可评审 — 关键决策、结构划分有据可查，支持团队评审
4. 风险可预判 — 提前识别风险并制定应对策略
5. 变更可追踪 — 版本记录保留所有变更历史

【如何使用本模板】
1. 按照各章节的字段说明填写内容
2. [必填] 章节必须填写，[可选] 章节按需填写
3. [按需] 章节根据方案类型决定是否填写
4. 保存到对应任务目录下

【适用场景】
- 软件开发：功能开发、架构设计、系统集成、问题修复
- 内容创作：小说、剧本、文案策划
- 活动策划：会议、展览、庆典
- 科研项目：实验设计、论文撰写
- 其他领域：任何需要系统规划的任务

【占位符说明】
- {xxx}：需要替换为具体内容的占位符
- [必填]：必须填写的章节/字段
- [可选]：按需填写的章节/字段
- [按需]：根据方案类型决定是否填写的章节/字段
============================================================
-->
