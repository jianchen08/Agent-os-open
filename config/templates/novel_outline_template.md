# 网络小说大纲模板

## 概述

本文档为网络小说大纲的标准化模板，包含完整的大纲结构指导。

## 结构

| 部分 | 说明 | 必填 |
|------|------|------|
| 基本信息 | 小说类型、篇幅、世界观简介 | ✅ |
| 世界观设定 | 背景设定、力量/规则体系、势力分布 | ✅ |
| 人物设定 | 主要角色、配角阵营 | ✅ |
| 主线剧情 | 主线概述、分阶段剧情 | ✅ |
| 章节大纲 | 详细的章节内容概要 | ✅ |
| 伏笔与悬念 | 埋设的伏笔和悬念设计 | ✅ |
| 爽点设计 | 核心爽点分布和设计 | ✅ |
