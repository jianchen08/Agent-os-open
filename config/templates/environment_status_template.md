# 环境准备状态报告模板

<!--
============================================================
【模板是什么】
环境准备状态报告是 Agent 在执行任务前检查运行环境后，输出的环境状态评估文档，
记录了环境检查的结果、资源状态、配置验证情况以及最终的就绪结论。

【模板的作用】
1. 前置检查 — 在任务执行前确认环境是否满足要求，避免执行失败
2. 问题预警 — 提前发现环境问题，给出解决建议
3. 决策依据 — 上层 Agent 可根据就绪结论决定是否开始执行
4. 基线记录 — 作为环境快照，便于后续对比和排查

【如何使用本模板】
1. 环境准备 Agent 通过 static_vars 加载本模板内容
2. 按模板章节顺序填写环境检查结果
3. [必填] 章节必须填写，[可选] 章节根据需要填写
4. 最终输出到 reports/{task_id}_environment_status.md

【适用场景】
- 新任务执行前的环境检查
- 依赖安装后的环境验证
- 环境变更后的状态确认
- 多环境间的配置对比

【与其他模板的关系】
- 下游：产出物被 resource_manager_agent 等上层 Agent 读取，作为任务执行的决策依据

【决策建议】
| 准备结论 | 上层 Agent 操作 |
|----------|----------------|
| 就绪 | 可以开始执行任务 |
| 未就绪（有阻塞项） | 先解决阻塞项，再重新检查 |
| 部分就绪 | 可执行不依赖阻塞项的子任务 |

【占位符说明】
- {xxx}：需要替换为具体内容的占位符
- [必填]：必须填写的章节/字段
- [可选]：按需填写的章节/字段
============================================================
-->
