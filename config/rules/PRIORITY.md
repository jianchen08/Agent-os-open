# 规则面跨文件优先级（PRIORITY）

> 适用范围：`config/rules/**` 规则文件之间、规则文件与 AGENTS.md 浓缩锚之间、
> 以及规则条款与其他提示词物料（agent 配置/技能包/模式包）之间的冲突裁决。
> 裁决按级先行、同级按源：

1. **P0 安全与正确性**：安全底线、数据完整性、权限与隔离约束。任何效率或
   风格条款不得推翻本级（例：「禁止盲目使用 enhanced_search」属工具误用
   防护，压过「写码前必须先搜」的效率性检索纪律）。
2. **P1 任务正确性**：需求契约、验收口径、测试有效性（断行为不断实现、
   防拟合、mock 边界）。
3. **P2 输出格式**：文件布局、命名、文档结构条款。
4. **P3 风格**：注释密度、措辞与示例偏好。

同级规则的源序：

- `per_domain/` 域规则全文 > `per_agent/` 角色规则 > 通用规则文件
  （如 `testing_rules.md`）；`per_agent` 只允许在域规则之上**收紧**，
  不允许放松。
- AGENTS.md 各节浓缩锚是对应全文的索引，全文优先于浓缩。
- 机械门禁（测试/格式/覆盖率/文件行数基线）优先于一切软约束；门禁之间的
  冲突以 `.github/` 基线文件与 `scripts/run_gates.py` 接线为准，不另行解释。
