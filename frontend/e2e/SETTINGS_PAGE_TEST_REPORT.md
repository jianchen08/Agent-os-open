## 运行测试

### 运行所有 Settings 页面测试

```bash
cd frontend
npm run test:e2e settings-page
```

### 运行特定测试组

```bash
# 只运行页面加载测试
npm run test:e2e -- -g "页面加载和标签切换"

# 只运行 LLM 配置测试
npm run test:e2e -- -g "LLM 配置修改"

# 只运行 API 配置测试
npm run test:e2e -- -g "API 配置修改"

# 只运行工具配置测试
npm run test:e2e -- -g "工具配置修改"

# 只运行保存功能测试
npm run test:e2e -- -g "保存设置功能"

# 只运行综合场景测试
npm.run test:e2e -- -g "综合场景测试"
```

### 调试模式

```bash
# 显示浏览器窗口
npm run test:e2e -- --headed --project=chromium settings-page.spec.ts

# 慢速执行
npm run test:e2e -- --slow-mo=1000 settings-page.spec.ts

# 调试模式
npm run test:e2e -- --debug settings-page.spec.ts
```
